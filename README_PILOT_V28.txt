STVDIØ Climate Technology Atlas — Pilot v28

ENTREGA
Versión estática lista para revisión local y posterior publicación en GitHub Pages.
Conserva la arquitectura visual y editorial de la versión 27.

CAMBIOS PRINCIPALES
- Atlas reconstruido con las tablas técnicas refinadas en inglés, español y alemán.
- 458 tecnologías alineadas en cada idioma.
- 883 relaciones normalizadas entre tecnologías y materias primas en cada idioma.
- Perfiles ampliados con función climática, ciclo de vida y clasificaciones justificadas.
- Requisitos transversales: infraestructura, energía, materiales/insumos y suministro/repuestos.
- Desglose detallado de Hardware, Software y Orgware.
- Fuentes por registro: CTCN, tipología, IIASA, referencias técnicas y materias primas.
- Búsqueda ampliada sobre descripciones, clasificaciones, componentes, requisitos, materiales y fuentes.
- Mapa de suministro compatible con nombres de países localizados mediante códigos ISO-3.
- Navegación progresiva conservada: Rama → Sector → Grupo → Tecnología.
